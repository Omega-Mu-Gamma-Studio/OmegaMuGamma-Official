About the studio

We're students who ship.

Omega Mu Gamma Studio is a student-run software studio based at St. Xavier's Catholic College of Engineering in Nagercoil, Tamil Nadu. We design and build deployed educational tools — apps that real learners use, not just semester projects that collect dust.

🚀

Ship first

Every project in our catalog is deployed and publicly accessible. We believe the best code is code that someone actually runs.

🎓

Learn by building

Our tools are built to teach — but so is building them. Every app is a real engineering challenge our team solves together.

🌐

Open source everything

All our code is public on GitHub. Other students, faculty, and contributors can fork, learn from, and improve everything we make.
